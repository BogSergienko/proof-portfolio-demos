Анализатор проверяет ссылки на источники, версии документов, совпадения значений и запрет на действия после STOP.

  • Неверная сумма → VALUE_MISMATCH
  • Старая версия → STALE_VERSION
  • Запись после STOP → BLOCKED_STOP

Как проверить самому?

Нужен Python 3.10 или новее. Запуск в корне репозитория:

python -m unittest discover -s tests -v

Программа не требует внешних библиотек, доступа в сеть, паролей или клиентских документов. Результат можно воспроизвести на своём компьютере.
